# Alex-Fin 研究架构

[English](architecture.md) | 简体中文 · [首页](../README.zh-CN.md)

Alex-Fin 把资产配置建模为序列决策问题。策略在决策截止时刻读取已经可用的信息，结合资产特征与市场特征，生成目标权重。执行模型把目标权重转化为持仓与收益，学习过程再根据风险调整反馈更新策略。

本页依据作者提供的投资组合研究稿与架构文档重新撰写，说明研究系统的设计。已发布模块及其与设计的当前差异见[源码导航与实现核查](source-status.md)，公开复现需要的运行材料见[实验结果](results.zh-CN.md)。

## 模块与接口

| 模块 | 输入 | 输出 | 核心职责 |
| --- | --- | --- | --- |
| 信息可用性与预处理 | 价格、成交量、基本面、可用时间戳 | 各资产、各频率的历史序列 | 执行决策截止规则，只用允许的历史拟合变换。 |
| 频率表征 | 各原生频率的数据块 | 统一隐空间维度并带频率标识的 Token | 保留采样分辨率差异。 |
| 图估计 | 每个频率的历史观测 | 各频率独立的资产邻接矩阵 | 提供统计关系结构。 |
| 并行时间与空间注意力 | Token、时间掩码、图掩码 | 资产级时间特征与关系特征 | 学习序列规律和跨资产关联。 |
| 跨频率注意力 | 各频率表征 | 融合后的资产表征 | 在信息可用性掩码约束下交互。 |
| 稀疏专家 | 融合 Token | 自适应特征 | 结合共享结构与路由专业化。 |
| 策略与可行配置 | 自适应特征、当前持仓 | 风险资产及现金的目标权重 | 满足已声明的组合约束。 |
| 执行与学习 | 目标权重、成交规则、收益、成本 | 持仓、奖励、策略更新 | 分开处理经济记账和训练目标。 |

设资产数为 $N$，频率 $f$ 的原始观测形状为 $T_f\times N\times d_f$。分块投影可把它映射为 $L_f\times N\times D$，不要求各频率序列等长。掩码需要区分“观测不可用”和“观测值确实为零”。季度基本面还需要公告发布时间；季度结束日期不能直接代表信息已经公开。

## 文档记录的设计参数

研究设计使用秒、分钟、小时、日、周、月、季度七类频率，隐空间维度为 256，注意力头数为 8，Dropout 为 0.1，空间图注意力为单层。混合专家包含一个共享专家与八个路由专家，每个 Token 同时激活共享专家及其中两个路由专家。专家分工通过学习形成，设计没有把某位专家永久指定给某种市场状态。

投资组合包含现金，采用多头、无杠杆约束，目标权重之和为一。研究稿还规定单行业权重不超过 25%。即使风险资产少于四个行业，现金也能使约束保持可行。

## 图的构建与方向含义

Graphical Lasso 通过稀疏精度矩阵目标估计关系：

$$
\widehat\Omega_f=\arg\min_{\Omega\succ0}\{\operatorname{tr}(S_f\Omega)-\log\det\Omega+\lambda_f\|\Omega\|_{1,\mathrm{off}}\}.
$$

$S_f$ 为历史样本协方差，$\lambda_f$ 控制稀疏程度。在高斯假设下，精度矩阵的非对角元素为零对应条件独立。精度矩阵具有对称性。这种统计关联可以作为图先验，但单凭它不能识别未来一段时间内的冲击传导。

研究稿提出对精度矩阵元素平方进行归一化，并将该构造称为 GLASSO-DY。它与 Diebold–Yilmaz 预测误差方差分解的等价性还需要推导验证。行归一化可以产生不对称权重，但没有因此加入时间传播机制。忠实复现应把稿件公式保留为明确命名的方法变体，再与定义完整的动态溢出估计器比较。[案例一](../cases/01-causal-multifrequency-graphs.zh-CN.md)通过数值解释这一差别。

## 策略学习与组合记账

设计采用微分夏普比率（DSR）奖励，递推更新收益的一阶矩和二阶矩，并加入换手惩罚。群组相对策略优化用于比较同一状态下抽样得到的配置动作，其优势形式为：

$$
\widehat A_g=\frac{r_g-\bar r}{s_r+\epsilon}.
$$

同一组中的候选动作需要共享相同的初始持仓、市场状态、奖励矩状态和后续评价区间，并在独立环境副本中计算。否则，候选动作的评价顺序就可能影响结果。组内归一化本身不能证明梯度无偏，也不能保证更强的泛化能力。

Softmax 保证权重为正且总和为一；行业上限仍需要明确的额外构造，例如约束优化层或具有上限的分层配置。策略比率使用的概率密度必须对应实际抽样的动作表示；把高斯动作变换为受约束权重时，需要准确规定似然的计算方式。

奖励是训练信号。组合表现需要通过自融资净值账本计算，包含真实成交价、持仓漂移、现金、费用和未成交订单。换手惩罚本身不是现金扣费。[案例二](../cases/02-risk-rewards-and-evaluation.zh-CN.md)会逐步计算这些区别。

## 公开复现需要记录的决策

1. 明确每一个滚动窗口的训练、验证、测试边界。研究稿描述 5/1/1 年划分，架构文档另有 7/1/1 年表述；公开运行清单需要消除这一差异。
2. 使用当时可知的指数成分和发布时间，说明退市、停牌、公司行动与缺失频率的处理。
3. 定义图对角线、归一化顺序、无邻居情形、边方向、估计窗口，以及不接触测试集的参数选择规则。
4. 定义可行动作映射，以及它对策略似然和行业暴露的影响。
5. 分开记录奖励惩罚与实际执行成本，说明执行时间、交易单位、现金利息和无风险利率转换。
6. 在保留测试集评估前冻结全部规则，发布各随机种子、各窗口结果及汇总指标。

以上事项使研究具备可检验性，不代表相应复跑已经完成。文档来源与基础文献见[来源说明](sources.md)。
